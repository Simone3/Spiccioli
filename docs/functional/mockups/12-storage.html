When something else changes the file

External modification
a line on whatever screen you are on · not a modal, and not a choice between two versions

This file was changed by something else while you had it open. That version has been saved to the backup folder as finances-2026-08-08-143207-848-external, and your work has been kept. That copy is one of the 10 backups kept there, so it will be rotated out in time — move it somewhere else if you want to keep it.
