§12.2

Conflict and read-only dialogs

File
the whole menu
New…a fresh file, categories seeded
Open…browse for one
Open Recent ▸the same list the launch screen offers
Quittakes the closing backup

Everything else the application does, it does on a screen. There is no Edit menu because there is no undo (§12), and no View menu because there is nothing to configure about the view.

Switching files
Open… or Open Recent, mid-session
1 · the open fileautosaved and closed
2 · the new filebacked up on open
3 · schemachecked as at launch
4 · the screenPortfolio, filters cleared

A file opened from the menu goes through exactly what a file opened from the launch screen goes through — the same backup, the same upgrade prompt, the same refusal if it cannot be understood. If it is refused, the file you had stays open and the message says why; the launch screen is not brought back mid-session.
