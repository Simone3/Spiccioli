Settings

12 preferences · applied as they change · no save button
● These settings belong to Spiccioli, not to the open file. They are stored with the application and apply to every file you open — change a separator here and the ledger you open tomorrow is written the same way. Nothing on this screen travels with finances.spiccioli if you send it to someone.

Every one is a closed set except the symbol: three date formats, one per order — DD/MM/YYYY · MM/DD/YYYY · YYYY-MM-DD; comma or dot for the decimal separator; dot, comma, space or none for thousands, which must differ from it. Display only: entry uses a date picker and a validated amount field, and an import reads the date order out of the pasted rows — neither consults anything here.
