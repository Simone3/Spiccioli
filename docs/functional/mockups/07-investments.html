§7.6

Update prices · choosing

The button opens a modal of two pages, and this is the first. Everything that will leave the machine is on it, per row, before anything does: the listing, and the day the request starts from. Changing the span rewrites the Ask from column, so the cost of the choice is read rather than described.

Update prices
1 Choose2 Fetch and review
Latest quote only

One figure per security, whatever day the provider has it for. Keeps an open file current.

Since the last price

From the day after each security’s most recent price. One with no price at all is asked from its first purchase.

The whole history

From each security’s first purchase to today, or to its last sale where the position is closed. Fills a history in.

§7.6

Update prices · the review

The same table, unmoved. Each row says what came back and what writing it would do to the file: new days, days that would land on a different value, and days that already hold exactly this figure and are therefore not written at all. A row that failed is stated, disabled and unticked, and only a row whose answer could differ next time is marked can be retried.
